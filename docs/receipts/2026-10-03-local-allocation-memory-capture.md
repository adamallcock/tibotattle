`measure-local.mjs` accepts `--allocation-profile` and `--memory-profile`, requiring its existing `--worker-profile-dir` and exact `--worker-profile-source` pair. Both default off. Extension mode includes a fresh numeric main capture and owner/nested Workers in one 256-capture reservation. It uses unified 10ms CPU sampling; combining it with the separate `--cpu-profile` window settings is refused. CPU-only capture behavior and its previous caps remain unchanged. Production/staging/cloud targets are forbidden.

Each extended capture reserves CPU 1MiB, allocation 768KiB, memory 64KiB, numeric phase history 8KiB and summary 4KiB. Together with the 1MiB run metadata reservation, 256 captures remain below 512MiB persisted output. These are output caps, not hard limits on inspector response memory or process allocation. Duration is cooperative, bounded at ten minutes per isolate; forced exit, errors, overflow, missing artifacts or truncated work-phase history remain explicitly incomplete. Main completion requires drainage but no Worker exit event. Worker completion also requires its exit observation. Profiler faults do not replace computation failure or termination outcomes.

Allocation uses only `HeapProfiler.startSampling`/`stopSampling`, at 128KiB with minor/major collected-object flags explicitly true. A closed tree persists sanitized code frames and numeric statistical self weights; no heap snapshot, object value, object ID, sample ordinal, or private path is retained. Iterative traversal bounds nodes at 4096 and depth at 128 before serialization. Metadata, actual byte sizes, hashes, mode declarations and each artifact's closed schema are validated before a complete manifest can qualify.

Node 22.16 conformance verifies both flags are recognized by rejecting invalid boolean types and accepting true. The tiny synthetic collected-versus-live experiment frees its objects before stop; collected mode retains statistical allocation weights while live-only mode can report zero. This establishes sampled semantics, not exact allocated bytes. The flags are defined in the [Node 22.16 pinned inspector protocol](https://raw.githubusercontent.com/nodejs/node/v22.16.0/deps/v8/include/js_protocol.pdl). Forced GC is confined to this synthetic conformance test; the runtime helper never requests it.

Numeric memory retains bounded start/recent/end samples, observed peaks and maximum timer gaps. Main RSS is process-wide; Worker RSS is omitted. Samples can miss synchronous highs; GC notifications arrive asynchronously. Whole-window allocation frames do not identify objects at the RSS peak, and no residual is assigned to an invented component. Compare observed RSS samples with process maxRSS separately.
