# TiboTattle 0.1.25

This release restores direct Codex allowance reads when recent ChatGPT or
Codex desktop builds place their CLI at `Contents/Resources/codex-cli/bin/codex`.
TiboTattle also checks the older bundled location, both system and user
Applications folders, an explicit `CODEX_BIN` setting, and then `PATH`. The
doctor identifies the selected source and bundle layout without displaying a
private filesystem path. Local usage analysis remains independent of the CLI;
if a direct quota read cannot run, the previous observation remains stale.
Fresh local usage no longer relabels that old quota as live. After a terminal
refresh timeout, the dashboard gives cleanup a short grace period before
reporting that the analysis did not finish. A fresh allowance can appear while
the longer local usage analysis continues.

Since 0.1.24, the desktop source also adds a macOS update-available indicator,
repairs tray cleanup during updater shutdown, persists startup checkpoints
before early quits, warms cached dashboard reports across periods and speed
modes, and corrects the Trends header range on cached plan views. The model
catalog includes newly recognized Claude names.
The forecast-only GPT-6.1 Astra identity remains explicitly unpriced in local
Codex usage reports.
