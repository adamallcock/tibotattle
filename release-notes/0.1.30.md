# TiboTattle 0.1.30

This desktop release candidate recognizes GPT-6.2 Astra and GPT-6.2 Sol in
Codex usage, model performance, and exports.
A detailed **Refresh** can recover either model from retained logs, including
usage first read by 0.1.29. An older record whose model was saved as unknown
still needs its source log for identification. [OpenAI's November 17 release](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

The client also recognizes the exact GPT-6.2 Astra for Law ID in recorded
usage from approved workspaces. It keeps those records separate from ordinary
Astra. OpenAI lists the legal model at Standard speed and describes its
current pricing as promotional through at least December 31, 2026. This
candidate leaves later legal-model events unpriced pending further evidence.
[Astra for Law](https://openai.com/index/astra-law-6-2/) ·
[Enterprise rate card](https://help.openai.com/en/articles/20001415-chatgpt-rate-card-enterprise-token-based-pricing)

Standard API-equivalent prices per million tokens:

| Model | Input | Cached input | 30-minute cache write | Output |
| --- | ---: | ---: | ---: | ---: |
| GPT-6.2 Astra | $8 | $0.40 | $10 | $40 |
| GPT-6.2 Sol | $2 | $0.10 | $2.50 | $10 |
| GPT-6.2 Astra for Law | $8 | $0.40 | $10 | $40 |

These rates apply through 272,000 input tokens. Above that threshold the
whole request uses twice the input and cache rates and 1.5 times the output
rate. For GPT-6.2 Astra and Sol, Batch costs half the Standard rate and Fast
costs twice Standard. Ultrafast costs three times Standard through February
28, 2027, Pacific time. From March 1 at 00:00 Pacific (08:00 UTC), it costs
six times Standard.
Flex has no published rate for these models. Codex records aggregate cache
writes, so the comparison uses the default 30-minute retention price.
[OpenAI API pricing](https://developers.openai.com/api/docs/pricing)

For GPT-6.2 Astra and Sol, Fast uses included Codex allowance at twice the
Standard rate. Ultrafast uses it at six times Standard throughout the API
promotion. A turn can use Ultra reasoning at any supported speed. The
performance filters use the speed recorded for that turn.
[Codex speed and credit rates](https://learn.chatgpt.com/docs/pricing#speed-multipliers)

This version also recognizes Ultrafast API pricing for the earlier GPT-6.1
Sol from its October 8 launch at six times that model's Standard rate.
[OpenAI API changelog](https://developers.openai.com/api/docs/changelog)
