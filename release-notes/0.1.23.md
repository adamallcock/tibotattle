# TiboTattle 0.1.23

Remaining allowances become animated fuel tanks with one shared pace forecast,
reset countdowns and estimated run-out timing. Waiting states explain when more
fresh evidence is needed, and stale readings never imply active consumption.

Trends brings allowance, spending, quota comparison and cumulative drift into
linked charts with typed reset evidence. Allowance Value adds plan-specific
five-hour history alongside seven-day estimates.

The cache continuity matrix shows all time buckets together, with sample counts,
percentage-first inspection and model filtering. Shared dashboard controls and
loading states preserve the last matching results during refresh.

A local usage coach and Codex plugin can explain recorded usage through a
bounded, content-free protocol.

Windows file identities and collector/model-timing recovery are strengthened.
Windows model performance remains unavailable while its separate protected
reader qualification is open. This release preserves that feature boundary.
