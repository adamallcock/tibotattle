# TiboTattle 0.1.31

If an incremental local usage refresh is cancelled or TiboTattle closes before
it finishes, choose **Update local usage** again. TiboTattle can reuse saved
progress when the corresponding logs still match. The dashboard keeps showing
the last completed history while the refresh runs.

TiboTattle can pick up newly discovered logs on retry. If changes to the logs
invalidate saved progress, it starts a fresh incremental refresh from the last
completed index. The completed history counts each eligible usage event once.
