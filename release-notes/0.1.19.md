# TiboTattle 0.1.19 candidate

This candidate prepares the move to the Electron desktop app on Apple silicon
and Intel Macs, Windows and Linux. It is not yet a published stable release;
final installers and update feeds still need qualification against the frozen
0.1.19 source. The existing native 0.1.18 downloads remain available.

## Desktop and usage views

The new desktop shell includes configurable menu-bar and tray displays, an
allowance popup, notifications and automatic-update support. Tray values retain
valid observations with an explicit stale indication when a refresh is overdue.

Usage views have clearer overhead summaries, recognizable model icons and less
explanatory clutter. Allowance history distinguishes observations correctly, and
cache-detail lists identify when they show only the most recent records.

## Optional community contributions

The Electron app introduces accountless community contributions with an explicit
first-launch explanation and a persistent opt-out in Settings. Analysis remains
local, and contributions exclude prompts, responses and raw session content.
The signed staging rehearsal has passed; the separate production activation and
signed production canary are still pending. Installation does not itself prove
that the hosted service is ready.

## Release qualification

Earlier signed candidates provide platform and migration evidence, but do not
substitute for the final four-target 0.1.19 builds. Remaining physical Windows
and Linux desktop checks may be completed through user testing. Native Mac
handover, final artifact signatures, stable feed readback and preservation of
existing downloads remain separate publication checks.
