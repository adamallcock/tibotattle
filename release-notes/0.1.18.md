# TiboTattle 0.1.18

Unreleased candidate. No stable source tag or public Intel artifact exists for
this working version. These notes describe source work and must be finalized
against qualification evidence before publication.

## Separate macOS installers

This candidate prepares separate Apple silicon (`arm64`) and Intel (`x64`)
installers for macOS 14 or later, built from one release source. It addresses
[issue #93](https://github.com/adamallcock/tibotattle/issues/93) without changing
the already published 0.1.17 assets or tag.

The Intel build uses the native launcher, bundled Intel Node runtime and native
Keychain broker. Its updater uses a separate feed; existing Apple silicon
update URLs stay unchanged. The website has separate macOS tabs and exposes
Intel downloads only when their own validated release evidence is supplied.

The candidate allocations are internal-dogfood build `1025` and stable build
`1026`, shared across the two architectures. Allocation is not evidence that
either build has been signed, installed or released.

A signed and notarized Intel build 1025 is now prepared for a tester; its
[local verification receipt](../docs/receipts/2026-09-03-macos-intel-signed-candidate.md)
does not establish physical Intel support or public availability.

## Qualification boundary

Intel is not yet a supported public platform. Physical Intel testing, silent
Keychain operation, login items, signed and notarized final installers,
candidate-to-candidate update installation and public download verification
remain required. Cross-compilation and Rosetta smoke tests do not establish
those results. No new Homebrew Intel support is claimed.

Follow the [Intel implementation plan](../docs/plans/2026-09-03-macos-intel-release.md)
and [macOS release runbook](../docs/runbooks/macos-stable-release-runbook.md).
