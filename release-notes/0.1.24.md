# TiboTattle 0.1.24

Draft release notes. Final model pricing is integrated; release qualification continues.
Telemetry v1.2 and the Standard/Fast correction are integrated; hosted rollout
and final artifact qualification remain in progress.

GPT-6 Sol and Luna have distinct client and server API-price-equivalent rates
for Standard, Batch, Flex and Fast modes, including cache reads, cache writes
and long context above 272,000 input tokens. They reuse their GPT-5.6 family
icons while preserving older models and historical pricing.

Model performance becomes available in Windows Electron. Tool-free turn
throughput complements output speed, while cached performance and work reports
remain visible during refresh.

Projects & threads repairs Windows saved task-name lookup and project grouping,
including Windows Git output and saved repository origins when Git is unavailable.
Windows also reads Codex's selected task-history heads, preserving valid forked
tasks when a paginated history has multiple physical files. macOS and Windows
share the same metadata parity tests and avoid creating source sidecars when
reading a closed database. This fix has native metadata and packaged dashboard checks; their
exact-candidate Windows qualification remains required before publication.

Automatic refresh recovery is more resilient, and start-at-login status updates
without reopening Settings. The tray presents clearer pace and run-out timing.
Local opt-in crash capture and an offline support doctor make startup failures
easier to investigate.

History ingestion now distinguishes accounting records from nested session
content and accepts rollout lines up to 512 KiB. Parser recovery preserves
previously indexed usage and avoids adding it again on restart.

Optional sharing recovers from more temporary service failures and schedules
an upload after a successful index update. Local diagnostics distinguish refresh
progress from upload progress. Durable opt-outs and retry backoff remain in place.

Model performance keeps Standard and Fast results separate, defaults
to Standard, and counts historical measurements with unknown mode as excluded.
Sparse Fast samples retain their actual counts.

Required telemetry v1.2 adds qualified turn-boundary and continuity evidence
while preserving older-client compatibility and existing cache calculations.
Its hosted rollout and final installed-client checks must pass before these
notes can become a publication claim.
